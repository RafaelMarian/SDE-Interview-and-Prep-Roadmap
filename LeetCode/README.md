# LeetCode — Blind 75 & Top Interview 150 (C++)

Soluții **explicate** în C++ pentru cele două liste standard de pregătire FAANG.

| Listă | Fișier index | Probleme |
|-------|--------------|----------|
| **Blind 75** | [Blind75/README.md](./Blind75/README.md) | 75 — esențialul NeetCode |
| **Top Interview 150** | [Top150/README.md](./Top150/README.md) | 150 — lista oficială LeetCode |

Soluțiile comune stau în [`solutions/`](./solutions/) (un fișier per problemă). Indexurile le leagă; overlap-ul Blind75 ∩ Top150 e un singur fișier, referit din ambele.

## Format fiecare problemă

1. Enunț pe scurt + tip / difficulty  
2. **Intuition** — de ce merge abordarea  
3. **Approach** — pași  
4. **Complexity** — timp / memorie  
5. **C++ Solution** — cod gata de lipit în LeetCode  

## Cum studiezi

1. Încearcă 20–30 min pe LeetCode fără să te uiți.  
2. Citește Intuition + Approach, re-implementă din memorie.  
3. Compară cu soluția din `solutions/`.
